# Over Project V2

Sitio estático de Over Project (overprojectversion2.vercel.app). Vercel publica solo cada cambio en `main`.

- **Editar textos, servicios, planes, pilares, portafolio y teléfono:** entra a `https://overprojectversion2.vercel.app/#editor`
  (o "Acceso editor" en el pie de página) con el correo y contraseña de tu editor de Over Project.
  Los cambios se guardan en Firebase (documento `content/siteV2`), separados del sitio oficial.
- **Videos de portada:** `videos/`. **Logo:** `img/logo.png`. **Modelo 3D:** `models/hoodie.glb`.
- Este repo contiene el sitio ya compilado (`assets/`); el código fuente vive aparte.
